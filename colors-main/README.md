# Анализатор цветов изображения

Учебный проект, команда: Щукина Анастасия, Рыбакова Алиса (ИСП 225-п).
Стек: Python 3.10+, Flask, Pillow, SQLite (стандартная библиотека).

## Запуск
1. Установить Python 3.10+ (с галочкой Add to PATH).
2. В папке проекта: `pip install flask pillow`
3. Запуск: `python app.py`
4. Открыть в браузере: http://127.0.0.1:5000
5. Создать аккаунт через «Регистрация», войти.

## Функции (7)
1. Регистрация пользователя (имя 3–20 символов, пароль от 4).
2. Вход / выход (сессии, пароли хранятся в виде sha256 с солью).
3. Загрузка фотографии (png, jpg, jpeg, webp, bmp, gif; до 10 МБ).
4. Анализ цветов: палитра с HEX-кодами, названиями и долями; выбор количества цветов (1–16).
5. Сохранение палитры с названием в базу данных.
6. Просмотр сохранённых палитр и фотографий («Мои палитры»).
7. Экспорт палитры в .txt и .png, удаление палитры.

## Структура
- app.py — сервер и вся логика
- templates/ — HTML-страницы
- uploads/ — загруженные фото (создаётся автоматически)
- database.sqlite3 — база (создаётся автоматически)
- check_examples.py — автопроверка анализа на примерах (`python check_examples.py`)
- TEST_CASES.md — таблица тест-кейсов (День 5)
- DEFECTS.md — журнал дефектов и исправлений (День 5)

## Ограничения
Количество цветов 1–16; форматы png/jpg/jpeg/webp/bmp/gif; файл до 10 МБ;
названия цветов приближённые (ближайший из базового набора), HEX точные.
